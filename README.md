识谱、节奏、演奏可直接选择，无解锁前置条件。练法、左/右/双手、整曲/任意两小节范围相互独立；手动选择后退出建议流程，完成后不会强制跳入另一练法。

## 2.4 整首琴谱与音符弹出动画

弹奏页始终呈现整首曲谱，支持向上、向下滑动；练习到下一行时自动跟随。分句练习的评分范围仍为当前小段，指示条、唱名、花朵和错音框映射回整首曲谱的原位置。完成一小段后不会误亮下一段。每个实际弹过的音符在对应位置弹出花朵与闪光，放大、上浮、淡出后保留小花；快速连续音可同时显示多个动画，漏弹不触发动画，并适配系统减少动态效果设置。

## 2.3 弹奏页布局

参考大谱面练琴布局：顶部集中放置重来、试听、琴键和设置，下一行可直接选左手、右手、双手。曲名和乐句范围放在谱面上方，当前音符显示粉色竖条与固定唱名，未练习的手部声部淡化。底部保留默认展开的琴键、简短提示和开始/暂停。移除遮住谱面的准备卡片，粉色与小兔、小花风格保留。

iPad 使用全屏窗口，支持横竖屏；不提供分屏。五线谱仍可在设置中放大。识音算法和评分规则未改动。

# 琴芽 PianoBloom 2.2 · 小兔钢琴花园

面向孩子的 iPhone / iPad 原生钢琴练习 App。粉色花园曲库、独立全屏演奏页、双行双手琴谱、实时光标与练习记录。

## 运行

用 Xcode 打开 `PianoBloom.xcodeproj`，在 Signing & Capabilities 中选择自己的开发团队，连接 iPhone 或 iPad 后运行。最低 iOS / iPadOS 16。支持横竖屏、iPad 分屏与安全区域。

## 双手与输入

- USB MIDI：用电钢琴 USB MIDI 线和相应 iPad / iPhone 转接器连接，在首页选择 MIDI 输入端口；读取真实 Note On/Off，允许两只手的起音在短窗口内组成一个音组。缺一只手不会通过。支持超过两个音的收尾和弦。
- 麦克风：保留单音识别；双手为本地频谱多音识别测试模式，基于非负谐波模板拟合，不读取目标琴谱来“猜”弹奏音。八度、泛音、弱音、踏板与真实钢琴音色会影响结果。所有麦克风分数标记为估算，正式评分推荐 MIDI。未宣称达到商业声学陪练准确率。
- 音频在设备处理，不保存录音、不上传。不要踩踏板，保持环境安静。

## 演奏与评分

首页音叉按钮保留自由单音识音，可探索音名，不计分。

先选曲、选左右手或双手、速度、跟谱或节奏挑战，点击进入小小音乐会。演奏时谱面单独全屏显示，iPad 展示多行谱和键盘。

- 跟谱：一小节预备后，每弹一个音组便前进，错音保留红色记录后自动继续，不给节奏分。
- 节奏挑战：一小节预备后按固定 BPM 网格前进；错音不会重置拍点；漏弹计 0；有偏早、偏晚反馈。暂停会平移计时原点以保留当前拍位。
- 音符分：正确音组 / 总音组（错音和漏弹各按该音组记 0）。节奏分：每组起音与目标拍点的偏差线性换算至 0–100 后取平均，漏弹为 0。只评起音时间，不评指法、力度、松键时长和音乐表现。
- 麦克风使用音频采集时间戳；设置中可补偿设备延迟。采样分析窗口带来延迟，计分等待缓冲不会改动拍点网格。

## 曲库

小星星、欢乐颂为启蒙双手改编，彩虹音阶双手八度同向；哈农第 1–20 首保留原谱双手音区、时值及结尾和弦，展开反复，并支持两小节选段。曲谱署名和授权见 [HANON_SOURCES.md](HANON_SOURCES.md)。

## 验证

`bash scripts/test-core.sh` 测试生产音高、多音 PCM 分析、MIDI 字节解析、双手匹配、固定网格评分、漏弹、暂停、反复和曲谱完整性。GitHub Actions 运行核心测试、模拟器编译、未签名真机编译，并从实际运行的模拟器导出 iPad 曲库、全屏琴谱和带练界面截图。完整手机与横屏截图可手动运行 `python3 scripts/capture-previews.py`。截图启动参数仅在 Debug 编译启用；“已弹奏”界面示例通过测试音符生成标记并在截图内标注，不启动输入、不保存练习成绩。

真机麦克风、不同琴型的多音准确率及 USB MIDI 连接仍需实测，参见 [DEVICE_TESTING.md](DEVICE_TESTING.md)。

## 2.1 小兔带练流程

参考用户提供的视频交互顺序，使用琴芽自己的粉色小兔视觉：曲库搜索 → 小兔带练 → 两小节右手 → 左手 → 双手 → 节奏挑战 → 小段演奏 → 下一段 → 整曲演奏。

- 双手音符分达到 70，或完整练习 3 次，进入节奏挑战；节奏挑战与演奏要求音符、节奏分都达到 90，或完整练习 3 次。
- 逐曲保存阶段、当前乐段和尝试次数；也可选“自由练习”直接进入原有练琴页面。
- “先听示范”播放本机合成音符并同步键盘，不是原视频或真人教师录像。示范不启动麦克风，不产生练习成绩。
- 可播放中文练习说明；弹奏时错音只显示画面提示，不再暂停输入或播放语音，防止 App 自己的语音被识别成钢琴。
- 谱线与音符默认 135% 大小、加深颜色和加粗，提供 100–170% 大小调节；手机每行 4 个音组，iPad 每行 8/16 音组。
- 绿色表示正确，红色表示当前错音，灰色表示漏弹，早晚起音有红色偏移影子，粉框标出需复习的小节；结束后能选择这些小节直接重练。

此更新完善交互流程和读谱体验，没有把尚未验证的麦克风识音改称已修复，也不提供未经验证的力度、指法或音乐表现评分。

## 2.2 连续弹奏交互

- 演奏页顶部“左手／右手／双手”均可直接切换，带练前三个步骤也可点选。保持当前练习范围，从本段开头重新计分；原先正在聆听时自动恢复，示范中切换则重新示范。
- 跟谱中错音自动记为错误并前进，不暂停、不要求再点开始。和弦的剩余输入在短合并窗口内不会再次消耗下一个音组。节奏挑战保持原有固定拍点与结束时值。
- 已实际弹奏的音组上方保留卡通小花，并短暂弹出开花动画；绿色小花表示弹对，粉色小花表示已经记录错音，漏弹不会伪装成已弹奏。
- 手机和 iPad 演奏页默认展开琴键；横屏窄高页面缩小琴键高度。可在字号设置中收起／展开。

本版没有改动麦克风音高分析算法，真实钢琴识音准确性仍需独立修复验证。
