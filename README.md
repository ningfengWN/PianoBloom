## 3.0 拍照录谱与唱谱双模式

首页及教材曲目提供拍照/相册录谱。最多四页，OpenAI Responses 图像识别（实验功能，需自行填写 API Key，可产生 API 费用）后对照照片核对、修正音高和拍点，确认后保存并进入原有演奏/心流评分。也可不调用 API，手动输入音符。Key 保存在本机钥匙串；只有用户点发送才上传照片，API 设置 store=false。额度不足或账单上限错误后自动停用后续识谱，无自动重试，手动恢复；限流、网络错误也结束本次请求。照片、修正数据保存在设备 Documents/PhotoScores，重启可恢复，原谱照片在弹奏页查看。

当前仅支持固定 2/4、3/4、4/4 拍，导入谱以实际起音对齐，独立声部时值、连音线等显示可能简化；复杂谱须逐音核对。没有服务 Key 时自动识别不可用；不宣称照片 OCR 准确率已达陪练要求。

唱谱练习分为识谱（只评音高、唱错停留标红、唱对自动继续、同音需重新起音）及心流（固定速度持续推进、汇总音高和节奏），听示范是独立按钮。唱谱页不显示音名字母、唱名提示气泡。人声判断仍用单音 YIN，不使用钢琴 O&V 模型。

## 2.9 教材书架

根据用户提供的封面和目录，新增小汤三全媒体升级版、考级精品教材一级～六级、孩子们的哈农修订版。小汤三和考级教材可按曲名、作曲家、级别与组别查看目录及页码。孩子们的哈农目前仅确认版本；所有新增教材目录均未绑定可评分音符数据，界面明确标注待录入，需实际谱页继续录入。原哈农1–20和启蒙曲仍在原曲库练习。

## 2.8.3 更清晰的谱面与节拍声

弹奏和唱谱页的谱线、音符统一放大 16%，谱线加深加粗，减少谱面两侧留白，每行仍为三个小节。节拍器提高普通拍和重拍振幅并延长敲击声，保留第一拍重音。实际音量取决于设备媒体音量。

## 2.8.2 每行三小节

弹奏和唱谱页均按实际拍号每行排三个完整小节，末行显示剩余小节；不同音符数量不会改变换行位置。整曲滚动、自动跟随和已弹音符动画按小节行定位。

## 2.8.1 唱谱准备与节拍器修复

唱名写入采用独立语音合成器，并同时处理结束音频缓冲、完成及取消回调；单唱名 8 秒、整个准备流程 30 秒超时，失败释放资源并可重试。分阶段显示唱名和旋律合成进度，取消或退出后后台任务不可恢复播放，音高分析最多检查 8 个窗口。播放 API 返回失败时明确报错。

弹奏页的说明、设置、节拍器统一由一个设置面板呈现，避免多个弹出层互相覆盖；点击节拍器立即开启并显示 BPM、滑块与逐拍微调。

## 2.8 顶部节拍器

弹奏页顶部「节拍器」可开关声音，支持 30–120 BPM 滑块和逐拍微调，第一拍加重。速度同步练习；演奏中调速会重启当前范围并倒计时。暂停停止声音，继续时对齐拍子；退出或进入后台关闭。麦克风练习建议佩戴耳机，避免节拍声串入收音。

## 2.7 唱谱小舞台

唱谱是辅助入口，钢琴弹奏仍只有演奏、心流两种。唱谱内可选「听唱谱」和「我来唱」：前者用系统中文语音产生唱名音色，通过音高同步重叠相加合成按谱音高与时值的唱谱，五线谱同步高亮，明确标为合成示范；后者用单人声 YIN 音高和起音检测实验评测，不走钢琴 O&V 模型。可选择左右手旋律、原谱/移八度音区，和弦只唱最高音。

人声评测只评音高与起音，不识别孩子是否发出了正确唱名。缺少足够清晰起音时不强行给节奏分。系统中文语音不可用或无法提取有声音色时给出提示，不拿普通朗读或钢琴声冒充唱谱。曲谱、声部、音区或听/唱切换会停止原音频，退出及切后台会停止麦克风和播放。

## 2.6 双模式、倒计时声音、O&V 实验接入

练琴页面只保留演奏（纠错练习）与心流（连贯弹奏与复盘），左右手独立选择。开始前逐拍播放倒计时声音，最后一拍音色不同；可在设置关闭，暂停后立即停止。

新增真正的 Onsets & Velocities 官方预训练模型接入：**本版需要同一 Wi-Fi 下的 Mac 运行模型服务，不是 iPad 本地模型**。在家长设置选择引擎、填写 Mac 地址和连接码。基础识音仍可手动使用，连接失败不会伪装成功或自动降级。

启动：`bash Server/onsets_velocities/Start-Model.command`。详情见 [模型接入说明](Server/onsets_velocities/README.md)。模型使用准确的采音时间和已处理水位评分，页面显示实际处理延迟。缩短上下文的准确率以及 iPad 真机录音链路仍需验证，不能视为已达到成熟陪练效果。

## 2.5 心流音符标记与卡顿复盘

参照提供的图例：正确音绿色，错音与孤立漏音红色；心流中未演奏音符、卡顿/未演奏片段、错误较多片段灰色；抢拍与拖拍分别在音符前后显示红色音符重影；粉色括号标记不熟练的小节。心流节拍继续前进，结算页同时列出卡顿/未演奏与连续错误片段数量。

判定采用本 App 的明确规则：连续漏弹至少两组且总时值至少一拍，记为一处卡顿/未演奏片段；连续三组错音记为一处错误较多片段。颜色分类不改动原始错音、漏音和节奏评分，也不声称使用参考 App 的内部算法。

演奏模式：错音停在当前音符并显示正确音提示，持续收音，弹对后自动继续；音符分保留首次出错记录。心流模式：按固定节拍持续前进，错音与漏音不中断，结束后汇总错音、漏音、抢拍、拖拍与节奏分，并列出需复习的小节。两种模式均可直接选择，左右手与范围独立。

识谱、节奏、演奏、心流可直接选择，无解锁前置条件。练法、左/右/双手、整曲/任意两小节范围相互独立；手动选择后退出建议流程，完成后不会强制跳入另一练法。

## 2.4 整首琴谱与音符弹出动画

弹奏页始终呈现整首曲谱，支持向上、向下滑动；练习到下一行时自动跟随。分句练习的评分范围仍为当前小段，指示条、唱名、花朵和错音框映射回整首曲谱的原位置。完成一小段后不会误亮下一段。每个实际弹过的音符在对应位置弹出花朵与闪光，放大、上浮、淡出后保留小花；快速连续音可同时显示多个动画，漏弹不触发动画，并适配系统减少动态效果设置。

## 2.3 弹奏页布局

参考大谱面练琴布局：顶部集中放置重来、试听、琴键和设置，下一行可直接选左手、右手、双手。曲名和乐句范围放在谱面上方，当前音符显示粉色竖条与固定唱名，未练习的手部声部淡化。底部保留默认展开的琴键、简短提示和开始/暂停。移除遮住谱面的准备卡片，粉色与小兔、小花风格保留。

iPad 使用全屏窗口，支持横竖屏；不提供分屏。五线谱仍可在设置中放大。识音算法和评分规则未改动。

# 琴芽 PianoBloom 2.2 · 小兔钢琴花园

面向孩子的 iPhone / iPad 原生钢琴练习 App。粉色花园曲库、独立全屏演奏页、双行双手琴谱、实时光标与练习记录。

## 运行

用 Xcode 打开 `PianoBloom.xcodeproj`，在 Signing & Capabilities 中选择自己的开发团队，连接 iPhone 或 iPad 后运行。最低 iOS / iPadOS 16。支持横竖屏、iPad 分屏与安全区域。

## 双手与输入

- USB MIDI：用电钢琴 USB MIDI 线和相应 iPad / iPhone 转接器连接，在首页选择 MIDI 输入端口；读取真实 Note On/Off，允许两只手的起音在短窗口内组成一个音组。缺一只手不会通过。支持超过两个音的收尾和弦。
- 麦克风：保留单音识别；双手为本地频谱多音识别测试模式，基于非负谐波模板拟合，不读取目标琴谱来“猜”弹奏音。八度、泛音、弱音、踏板与真实钢琴音色会影响结果。所有麦克风分数标记为估算，正式评分推荐 MIDI。未宣称达到商业声学陪练准确率。
- 基础识音在设备处理；O&V 引擎将音频发往用户配置的 Mac，不保存录音。不要踩踏板，保持环境安静。

## 演奏与评分

首页音叉按钮保留自由单音识音，可探索音名，不计分。

先选曲、选左右手或双手、速度、跟谱或节奏挑战，点击进入小小音乐会。演奏时谱面单独全屏显示，iPad 展示多行谱和键盘。

- 跟谱：一小节预备后，每弹一个音组便前进，错音保留红色记录后自动继续，不给节奏分。
- 节奏挑战：一小节预备后按固定 BPM 网格前进；错音不会重置拍点；漏弹计 0；有偏早、偏晚反馈。暂停会平移计时原点以保留当前拍位。
- 音符分：正确音组 / 总音组（错音和漏弹各按该音组记 0）。节奏分：每组起音与目标拍点的偏差线性换算至 0–100 后取平均，漏弹为 0。只评起音时间，不评指法、力度、松键时长和音乐表现。
- 麦克风使用音频采集时间戳；设置中可补偿设备延迟。采样分析窗口带来延迟，计分等待缓冲不会改动拍点网格。

## 曲库

小星星、欢乐颂为启蒙双手改编，彩虹音阶双手八度同向；哈农第 1–20 首保留原谱双手音区、时值及结尾和弦，展开反复，并支持两小节选段。曲谱署名和授权见 [HANON_SOURCES.md](HANON_SOURCES.md)。

## 验证

`bash scripts/test-core.sh` 测试生产音高、多音 PCM 分析、MIDI 字节解析、双手匹配、固定网格评分、漏弹、暂停、反复和曲谱完整性。GitHub Actions 运行核心测试、模拟器编译、未签名真机编译，并从实际运行的模拟器导出 iPad 曲库、全屏琴谱和带练界面截图。完整手机与横屏截图可手动运行 `python3 scripts/capture-previews.py`。截图启动参数仅在 Debug 编译启用；“已弹奏”界面示例通过测试音符生成标记并在截图内标注，不启动输入、不保存练习成绩。

真机麦克风、不同琴型的多音准确率及 USB MIDI 连接仍需实测，参见 [DEVICE_TESTING.md](DEVICE_TESTING.md)。

## 2.1 小兔带练流程

参考用户提供的视频交互顺序，使用琴芽自己的粉色小兔视觉：曲库搜索 → 小兔带练 → 两小节右手 → 左手 → 双手 → 节奏挑战 → 小段演奏 → 下一段 → 整曲演奏。

- 双手音符分达到 70，或完整练习 3 次，进入节奏挑战；节奏挑战与演奏要求音符、节奏分都达到 90，或完整练习 3 次。
- 逐曲保存阶段、当前乐段和尝试次数；也可选“自由练习”直接进入原有练琴页面。
- “先听示范”播放本机合成音符并同步键盘，不是原视频或真人教师录像。示范不启动麦克风，不产生练习成绩。
- 可播放中文练习说明；弹奏时错音只显示画面提示，不再暂停输入或播放语音，防止 App 自己的语音被识别成钢琴。
- 谱线与音符默认 135% 大小、加深颜色和加粗，提供 100–170% 大小调节；手机每行 4 个音组，iPad 每行 8/16 音组。
- 绿色表示正确，红色表示当前错音，灰色表示漏弹，早晚起音有红色偏移影子，粉框标出需复习的小节；结束后能选择这些小节直接重练。

此更新完善交互流程和读谱体验，没有把尚未验证的麦克风识音改称已修复，也不提供未经验证的力度、指法或音乐表现评分。

## 2.2 连续弹奏交互

- 演奏页顶部“左手／右手／双手”均可直接切换，带练前三个步骤也可点选。保持当前练习范围，从本段开头重新计分；原先正在聆听时自动恢复，示范中切换则重新示范。
- 跟谱中错音自动记为错误并前进，不暂停、不要求再点开始。和弦的剩余输入在短合并窗口内不会再次消耗下一个音组。节奏挑战保持原有固定拍点与结束时值。
- 已实际弹奏的音组上方保留卡通小花，并短暂弹出开花动画；绿色小花表示弹对，粉色小花表示已经记录错音，漏弹不会伪装成已弹奏。
- 手机和 iPad 演奏页默认展开琴键；横屏窄高页面缩小琴键高度。可在字号设置中收起／展开。

本版没有改动麦克风音高分析算法，真实钢琴识音准确性仍需独立修复验证。
