# 琴芽 PianoBloom 2.0 · 小兔钢琴花园

面向孩子的 iPhone / iPad 原生钢琴练习 App。粉色花园曲库、独立全屏演奏页、双行双手琴谱、实时光标与练习记录。

## 运行

用 Xcode 打开 `PianoBloom.xcodeproj`，在 Signing & Capabilities 中选择自己的开发团队，连接 iPhone 或 iPad 后运行。最低 iOS / iPadOS 16。支持横竖屏、iPad 分屏与安全区域。

## 双手与输入

- USB MIDI：用电钢琴 USB MIDI 线和相应 iPad / iPhone 转接器连接，在首页选择 MIDI 输入端口；读取真实 Note On/Off，允许两只手的起音在短窗口内组成一个音组。缺一只手不会通过。支持超过两个音的收尾和弦。
- 麦克风：保留单音识别；双手为本地频谱多音识别测试模式，基于非负谐波模板拟合，不读取目标琴谱来“猜”弹奏音。八度、泛音、弱音、踏板与真实钢琴音色会影响结果。所有麦克风分数标记为估算，正式评分推荐 MIDI。未宣称达到商业声学陪练准确率。
- 音频在设备处理，不保存录音、不上传。不要踩踏板，保持环境安静。

## 演奏与评分

首页音叉按钮保留自由单音识音，可探索音名，不计分。

先选曲、选左右手或双手、速度、跟谱或节奏挑战，点击进入小小音乐会。演奏时谱面单独全屏显示，iPad 展示多行谱和键盘。

- 跟谱：一小节预备后，弹对一个音组才前进，不给节奏分。
- 节奏挑战：一小节预备后按固定 BPM 网格前进；错音不会重置拍点；漏弹计 0；有偏早、偏晚反馈。暂停会平移计时原点以保留当前拍位。
- 音符分：正确音组 /（总音组 + 额外错音次数）。节奏分：每组起音与目标拍点的偏差线性换算至 0–100 后取平均，漏弹为 0。只评起音时间，不评指法、力度、松键时长和音乐表现。
- 麦克风使用音频采集时间戳；设置中可补偿设备延迟。采样分析窗口带来延迟，计分等待缓冲不会改动拍点网格。

## 曲库

小星星、欢乐颂为启蒙双手改编，彩虹音阶双手八度同向；哈农第 1–20 首保留原谱双手音区、时值及结尾和弦，展开反复，并支持两小节选段。曲谱署名和授权见 [HANON_SOURCES.md](HANON_SOURCES.md)。

## 验证

`bash scripts/test-core.sh` 测试生产音高、多音 PCM 分析、MIDI 字节解析、双手匹配、固定网格评分、漏弹、暂停、反复和曲谱完整性。GitHub Actions 运行核心测试、模拟器编译、未签名真机编译，并从实际运行的模拟器导出 iPad 横竖屏与 iPhone 界面截图。截图启动参数仅在 Debug 编译启用，不启动输入、不伪造演奏成绩。

真机麦克风、不同琴型的多音准确率及 USB MIDI 连接仍需实测，参见 [DEVICE_TESTING.md](DEVICE_TESTING.md)。
