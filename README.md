# PianoBloom · 琴芽

独立的 iPhone / iPad 单音钢琴练习 App，使用麦克风识别琴音。

## 初版功能

- 中央 C（C4，标准约 261.63 Hz）校准，适应钢琴整体音高偏差。
- 实时显示音名、八度与频率；音频仅在本机处理。
- 内置中央 C 音阶、欢乐颂单音练习。
- 谱面当前音符高亮，弹对前进，弹错提示。
- 离开前台停止收音。

## 在 Mac 运行

1. 克隆本仓库，打开 `PianoBloom.xcodeproj`。
2. 在 Target → Signing & Capabilities 选择自己的 Team。如 Bundle ID 冲突，请修改 `com.pianobloom.app`。
3. 选择 iPhone / iPad 真机，运行并允许麦克风访问。最低 iOS 16。
4. 点击「校准中央 C」，弹中央 C 保持片刻，再练习。

使用 Xcode 和 iOS SDK，无第三方依赖。设备签名由开发者的 Apple 账号完成。

## 当前验证与限制

此版本是原型源码，尚未通过 Xcode 编译和真机收音验证。
当前开发环境为 Linux，无法验证 iOS UI、签名或音频硬件行为。

仅支持单音，建议关闭踏板并保持安静。没有完整双手和弦识别、曲谱导入、节奏评分或自动翻页。重复音通过短暂静音重新触发，钢琴余音可能影响识别。中央 C 校准仅校正整体偏移，不能修正每个琴键的调律差异。

## 版本管理

初始版本为 0.1。提交源码、工程配置与说明；本机签名状态、构建产物与 Xcode 用户设置不入库。后续功能建议在独立分支开发。
