# Hanon score attribution

Exercises 1–20: C. L. Hanon, The Virtuoso Pianist, Part I (1873), Schirmer 1900 source edition.
Digital score: Steve Taylor and Javier Ruiz-Alma, Mutopia-2015/07/23-2037.
Source: https://www.mutopiaproject.org/ftp/HanonCL/virtuoso-pianist-pt1/
License: Creative Commons Attribution-ShareAlike 4.0, https://creativecommons.org/licenses/by-sa/4.0/

The adapted note data in `HanonScores.swift` is distributed under CC BY-SA 4.0. The prior `Exercise.hanon` compatibility data in `PitchCore.swift` remains under the same terms.

Changes in 2.0: merge source MIDI note-on events by onset; attribute the lower and upper simultaneous voices to left and right hands (including cross-staff notation); preserve original registers, onset spacing and final chords; expand the written twofold repeat, which the source MIDI files do not expand. Source MIDI onset intervals are expressed in quarter-note beats; the closing half note is two beats. Fingering, dynamics, articulation and original engraving are omitted. This license applies to the adapted score data, not unrelated app code.

The grand staff is generated by the app. Rhythm assessment evaluates onset timing only. The microphone transcription path is experimental; reliable simultaneous-note input uses USB MIDI.
